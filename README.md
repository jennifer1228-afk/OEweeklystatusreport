# 前山美語週報 (Or English Weekly Report)

`index.html` is a snapshot of the live parent weekly report page
(https://claude.ai/artifact/BAX75tyQrXGCxeikXfrkrC), taken 2026-10-31.

- Class content is AES-GCM encrypted per class; parents unlock it with their student ID.
- The page is rebuilt nightly from Or English's monthly Synopsis sheets, so this snapshot goes stale. The live artifact is the source of truth.
- No passwords, teacher codes or student ID lists are stored in this repo. Keep `secrets.json` out of it.
